      How it works

      1. Enter a target. A domain or full URL, such as example.com or http://localhost:3000.
      2. Confirm authorization. Scans send real requests to the target, so only test what you are allowed to.
      3. Read the results. Every finding shows its severity, how sure the scanner is, the evidence, and how to fix it. Export as HTML, PDF, Markdown, JSON or CSV.
