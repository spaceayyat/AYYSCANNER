What would you like to check?

AYYSCANNER is a defensive security scanner. Check a website, this computer, or a software project's dependencies. It reports only what it actually observed, with a clear score and how to fix each problem. Everything runs on your computer.

Quick scan

Nothing to configure. Type a website, press the button. Checks HTTPS, certificate, security headers, cookies and exposed files (skips link checking, so it is fast).

A scan is running: View progress

Website scan

Scan a website over HTTP or HTTPS, including localhost and LAN addresses. One page is analysed passively.

Scan options

System scan

Checks the security settings of this computer. Read-only: nothing is changed.

What it checks

  • Operating system and version
  • Network ports that are open and listening
  • Permissions on sensitive files (Linux/macOS)
  • SSH server settings, if an SSH server is installed
  • Whether a firewall is present

Some checks need administrator rights. If one is missing, it is skipped and the report says so.

Project scan

Checks a project's dependencies for known vulnerabilities using OSV.dev. Reads requirements.txt, package-lock.json and pyproject.toml.

Needs internet. Only package names and versions are sent to OSV.dev, never your code.

      About
      
          
      
            
            
      AYYSCANNER
      
          
      
          
      A defensive security scanner with a local web interface and a command line. It looks for weaknesses and tells you how to fix them. It never exploits anything.
      
          
      Supported scan types
      
          
        
            
      • Website: HTTP/HTTPS, localhost and LAN. Headers, cookies, TLS, exposed files, page content.
        • 
            
      • System: this computer’s ports, file permissions, SSH and firewall.
        • 
            
      • Project: dependency vulnerabilities from OSV.dev.

      Help
      
        
      A plain-language guide. No security background needed.
      
      
      
      
      
        
      What can AYYSCANNER scan?
          
      Three things:
      
          
        
            
      • A website (http or https, also your own localhost or a device on your home/office network). It looks at how the site is set up: secure connection, security headers, cookies, files that should not be public.
        • 
            
      • This computer. Open network ports, permissions of sensitive files, SSH settings and whether a firewall exists.
        • 
            
      • A software project. It reads the list of libraries your project uses and checks each one against a public database of known vulnerabilities (OSV.dev).
        • 
          
      
        
      
        
      What it cannot do
          
        
            
      • It is not a hacking tool. It never exploits, breaks into, or changes anything.
        • 
            
      • It does not guess passwords, test logins or submit forms.
        • 
            
      • It cannot prove something is secure. A high score means the checks it ran found little. Other problems may exist.
        • 
            
      • It does not scan your source code for bugs, only the libraries you depend on.
        • 
          
      
        
      
        
      Website scanning limits
          
        
            
      • One page only. It analyses the address you give it, not the whole site.
        • 
            
      • No JavaScript is run. Content a page builds in the browser after loading is not seen.
        • 
            
      • No login support. It sees what a visitor who is not signed in sees. Pages behind a login are not scanned.
        • 
            
      • Only scan sites you own or have written permission to test. A scan sends real requests.
        • 
          
      
        
      
        
      System scanning
          
      Runs on the computer where AYYSCANNER is running. Some checks (such as listing every open port) need administrator rights; without them that check is skipped and the report says so. Linux/macOS file-permission checks do not apply on Windows.
      
        
      
        
      Project (dependency) scanning
          
      Enter the folder of your project. AYYSCANNER reads requirements.txt, package-lock.json and pyproject.toml. Only libraries with an exact version (for example flask==2.0.1) can be checked; unpinned ones are listed as informational.
      
        
      
        
      Why does a project scan need the internet?
          
      The list of known vulnerabilities lives on OSV.dev, a public service. AYYSCANNER sends it only package names and versions and reads back advisories. If OSV.dev cannot be reached, the scan tells you the results may be unavailable instead of saying everything is fine.
      
        
      
        
      How is the security score worked out?
          
      It starts at 100 and loses points for each issue, depending on how serious it is and how sure the scanner is (Critical 30, High 18, Medium 8, Low 3; suspected issues count half). One serious confirmed problem caps the score so many small wins cannot hide it. Notes and SEO tips never lower it. The same findings always give the same score. Open “How is this score calculated?” on any result for the details.
      
        
      
        
      What do Confirmed, Potential and Informational mean?
          
        
            
      • Confirmed: the scanner saw it directly.
        • 
            
      • Potential: there are hints, but only a person can tell whether it is a real problem. Check it manually.
        • 
            
      • Informational: good to know, no direct security impact.
        • 
          
      
        
      
        
      Something went wrong. What now?
          
        
            
      • “Unable to connect to the target.” Check the address, that the site or server is running, and your internet connection.
        • 
            
      • “Invalid URL.” Use a domain like example.com or a full address like http://localhost:3000.
        • 
            
      • “OSV.dev could not be reached.” Check your internet connection and try again.
        • 
            
      • “Permission is required.” Start AYYSCANNER as administrator to include that system check.
        • 
            
      • Every error has a Technical details section you can copy when asking for help.
